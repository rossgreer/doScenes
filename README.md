**doScenes Annotations Dataset**

This repository hosts the initial release of our doScenes annotations. The provided dataset is stored in the Annotations folder in a CSV format.

**Usage**

Researchers interested in using the dataset are encouraged to visit our doScenes GitHub repository for additional details and updates.

**Citation**

If you use this dataset in your research, please cite the original paper:

    https://arxiv.org/abs/2412.05893
